# Package index

## Interfaz moderna

Funciones principales para descubrir, describir y descargar series.

- [`metadata()`](https://jkunst.com/bcchr/reference/metadata.md) :
  Metadata de las series
- [`resolve_series()`](https://jkunst.com/bcchr/reference/resolve_series.md)
  : Resolver una descripcion a series del Banco Central
- [`describe_series()`](https://jkunst.com/bcchr/reference/describe_series.md)
  : Describir una serie del Banco Central
- [`get_series()`](https://jkunst.com/bcchr/reference/get_series.md) :
  Get observations for one Banco Central series

## Visualizacion

- [`plot_series()`](https://jkunst.com/bcchr/reference/plot_series.md) :
  Plot a Banco Central series

## API de bajo nivel / legacy

Acceso directo a las operaciones oficiales del Banco Central.

- [`bcch_GetSeries()`](https://jkunst.com/bcchr/reference/bcch_GetSeries.md)
  : Obtener los datos de una serie
- [`bcch_SearchSeries()`](https://jkunst.com/bcchr/reference/bcch_SearchSeries.md)
  : Obtener las series disponibles por frecuencia
